# 1.0 — Preset overhaul (Prologue-quality bank)

A user-approved **pre-tag** pass: make the default bank a great first impression, cut the
duplicates, fix the weak drums, and add preset delete/rename + collapsible menu categories.
Original patches — the Korg Prologue is the **quality bar, not a source to copy**. Board task #124.

## Quality bar (distilled from the Prologue's acclaimed factory bank)
The Prologue's 250 factory sounds (multiple pro sound designers) are loved because they are
**fat/warm** (thick oscillators, a touch of drive-grit rather than thin/sterile), **alive**
(they breathe — drift, slow motion, evolving timbre, not static), **characterful** (even a
bread-and-butter patch has a point of view), **broad** (a real spread of ethereal / lush /
bass / lead / keys / harder), **playable** (velocity + expression built in), and a handful
**show the synth off**. Those six principles — not the patches — are what we aim for.
(Refs: AudioTechnology, GreatSynthesizers, MusicRadar reviews.)

Our synth's own showcase surface: **wavetable morph** (WT POS), **unison** stack, **filter
drive + SAT** for grit, **motion reverb**, **self-oscillating filter**, tempo-synced LFOs.
(Exotic *routed* patches — LFO→WT-pos vowel morphs, env→anything — need the preset-format
extension to carry mod-matrix routes; that's **1.1**. Here we go as far as params + the fixed
LFO/velocity/drift routes allow.)

Redesign directions (brief — params at build):
- **Bright Lead** → a rich detuned-saw lead with a touch of drive + motion, velocity-opened
  filter, subtle unison; sits up front, sings, and shows off. The flagship.
- **Acid** → drop resonance a notch, soften the filter-env sweep, add a hair of drift; organic 303, not a whistle.
- **Bell Keys / Digital Bell** → keep one truly nice FM-ish bell with a long shimmer + motion.
- **Clav Bite** → tighter attack, a bit of drive, snappier decay.
- **Synth Pluck / WT Marimba** → more transient + character (keytrack, WT position, delay/reverb depth).
- **String Machine** → chorus + drift ensemble with movement (toward Strings Redux quality).
- **Flutes** → cut the noise level hard, gate it to the attack (breath, not hiss).

## Drum fixes (their own increment)
- **Cowbell** — retune the two squares to a musical interval; less clangy, more pitched.
- **Crash** — kill the resonant peak (lower reso / shift the band), brighter/more metallic wash.
- **Ride** — de-toy: tighter bell partials, less pitched-square character.
- **Splash** — remove the toy resonance (same fix family as crash).
- **Metal Hit** — less shaped/"compressed": open the amp/filter envelopes, let it ring naturally.
- **Noise Riser** — smoother sweep, less static-y.

## Mechanisms (in 1.0 per the user's call)
- **Preset delete + rename** — `PresetManager` gains `deletePreset` / `renamePreset` (file ops +
  guard against clobbering); the Load menu gets a per-user-preset **Delete / Rename** action
  (right-click or a small edit affordance). Factory presets are read-only (no delete/rename).
- **Collapsible menu categories** — the Load menu's category section headers become
  expand/collapse groups (remember state), so a long bank scans fast. No search/tags/favorites.
- **1.1 (deferred):** preset-format extension that saves mod-matrix routes → the exotic
  routed/LFO-morph showcase patches.
